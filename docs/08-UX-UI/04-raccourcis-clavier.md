# 08.04 — Raccourcis clavier

> Pour les power users. Optimisé pour la productivité.

## Navigation

| Raccourci | Action |
|---|---|
| `Espace + drag` | Pan |
| `Molette` | Zoom au curseur |
| `Ctrl + 0` | Reset zoom (100%) |
| `Ctrl + 1` | Zoom 100% |
| `Ctrl + 2` | Fit selection |
| `Ctrl + 3` | Fit content |
| `Ctrl + +/-` | Zoom in / out (centré) |
| `Arrows` | Pan d'un demi-viewport |
| `Home` | Recentrer à (0, 0) |

## Outils

| Raccourci | Outil |
|---|---|
| `V` | Select |
| `P` | Pen |

| `L` | Line |
| `A` | Arrow |
| `T` | Text |
| `N` | Postit (note) |
| `I` | Image (file picker) |
| `M` | Mindmap |
| `E` | Eraser |
| `Esc` | Back to Select |

## Personnalisation

V1.x : settings → keyboard shortcuts → réassignation.

## Plateforme

Sur macOS, `Ctrl` est remplacé par `Cmd`. BSE utilise la convention native de chaque plateforme.

## Affichage des raccourcis

- Tooltip sur tous les boutons inclut le raccourci
- F1 ouvre une cheatsheet plein écran
- Settings / About inclut la liste

## Tests

- Chaque raccourci documenté fonctionne
- Pas de conflit entre raccourcis
- Comportements cohérents Windows/macOS/Linux
