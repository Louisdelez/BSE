# 01.04 — Facilitation d'une session

> Comment animer une session efficace. Ce document est *prescriptif* — il sert aussi à inspirer le **mode facilitation** de BSE.

## Le facilitateur, rôle clé

La recherche est unanime : **un bon facilitateur double la productivité d'une session**. Sa mission :

1. Maintenir la **sécurité psychologique**
2. **Équilibrer la parole** (contenir les dominants, solliciter les silencieux)
3. **Time-boxer** chaque étape
4. **Capturer toutes les idées** sans filtre
5. **Rester impartial** — ne pas pousser ses propres idées

## Avant la session (préparation)

### Cadrer la question
- Formuler en *« How Might We… »* (Comment pourrions-nous…)
- ✅ « Comment pourrions-nous réduire le temps d'onboarding de 50 % ? »
- ❌ « Onboarding »
- ❌ « Comment révolutionner l'expérience client de bout-en-bout ? » (trop vague)

### Choisir l'équipe
- **4 à 8 personnes** est l'optimum.
- **Diversité** : fonctionnelle (UX, dev, business, support), expérience (junior/senior), cognitive (visuel, analytique…).
- Inviter une **« voix externe »** quand possible (utilisateur, partenaire).

### Préparer le matériel
- Présentiel : post-its (3 couleurs min), marqueurs, mur libre, timer.
- Distant / hybride : board BSE préchargé avec template, lien d'invitation, timer intégré.

### Brief en amont
- Envoyer la problématique **24-48 h avant**.
- Demander aux participants d'arriver avec **3 idées chacun**.
- Effet : la phase silencieuse est accélérée et plus riche.

## Pendant la session — structure type 60-90 min

| Étape | Durée | Objectif |
|---|---|---|
| 1. Accueil + check-in | 5 min | Détendre |
| 2. Icebreaker créatif | 5-10 min | Activer mode créatif |
| 3. Rappel règles | 2 min | Différer jugement, viser quantité |
| 4. Cadrage problème | 5 min | Vérifier compréhension partagée |
| 5. Génération individuelle silencieuse | 10-15 min | **Clé** : évite production blocking |
| 6. Partage + rebond | 20-30 min | Stimulation cognitive |
| 7. Affinity mapping | 10 min | Regrouper |
| 8. Convergence (vote, priorisation) | 10-15 min | Sélectionner |
| 9. Plan d'action | 5 min | Qui fait quoi quand |

### Sur les icebreakers
Quelques classiques :
- **« 30 cercles »** : remplir 30 cercles avec des dessins en 3 min → libère la créativité.
- **« Pire idée »** : générer la pire solution possible → casse la peur du jugement.
- **« Mot impossible »** : donner un mot aléatoire, l'associer au sujet.

### Sur la phase silencieuse
**C'est la phase la plus oubliée et la plus importante.** Sans elle, on perd 30-50 % d'idées (production blocking). Règle : **toujours commencer par 10 min silencieuses**, même si le groupe résiste.

### Sur le rebond
Les règles de l'animateur :
- ✅ « Oui, et… » (rebond constructif)
- ❌ « Oui, mais… » (jugement déguisé)
- Reformuler les idées floues sans les juger
- Rendre visible les liens entre idées

## Mode facilitation dans BSE — fonctionnalités ciblées

Ces features sont inspirées de Mural et adaptées à BSE :

### 1. Mode facilitateur
Un participant a le rôle *facilitator*. Il peut :
- Lancer / arrêter un **timer** visible par tous
- Activer le **mode privé** (les ajouts d'un participant ne sont visibles qu'après reveal)
- **Summon all** : recentrer la caméra de tous les peers sur une zone
- **Spotlight** : suivre la caméra d'un participant (« regardez ce que je fais »)
- **Verrouiller** des éléments
- Lancer un **dot vote** avec budget configurable

### 2. Phases scriptées
Un template peut définir un **script de session** : enchaînement de phases avec durée et instructions.

```
Phase 1 — Génération silencieuse [10 min]
   Mode privé activé.
   Consigne : « Écris 5 idées sur des post-its jaunes »

Phase 2 — Partage [15 min]
   Mode privé désactivé. Tour de table verbal.

Phase 3 — Regroupement [10 min]
   Action : déplace les post-its similaires côte à côte.

Phase 4 — Vote [5 min]
   3 votes par personne.
```

BSE peut gérer automatiquement ce script, basculer les phases, afficher le timer.

### 3. Mode anonyme
Chaque post-it / dessin **n'affiche pas son auteur** (mais le système le sait pour modération). Réduit l'évaluation apprehension.

### 4. Mode focus
Le facilitateur peut imposer à tous les participants de voir **uniquement leur propre zone** pendant la phase de génération silencieuse. Reveal à la fin de la phase.

## Erreurs classiques à éviter

1. **Question floue** → recadrer avant de commencer.
2. **Pas de phase silencieuse** → 30 % de pertes minimum.
3. **Pas de convergence prévue** → 200 post-its qui finissent à la poubelle.
4. **Voix fortes qui dominent** → utiliser brainwriting / mode anonyme.
5. **Pas de suivi** → assigner immédiatement les actions, sinon meurt.
6. **Trop de monde** (>10) → casser en sous-groupes.
7. **Trop court** (<30 min) → impossible de bien diverger ET converger.
8. **Trop long** (>2 h sans pause) → fatigue, qualité chute après 90 min.

## Bonnes pratiques pour le facilitateur dans BSE

- 📌 Préparer la toile **avant** la session — pas pendant.
- 📌 Faire un *« tour de chauffe »* avec un sujet bidon de 2 min — permet à chacun de tester pan/zoom, créer un post-it.
- 📌 Encourager **chacun à utiliser sa propre couleur** pour identifier visuellement.
- 📌 Sauvegarder un **snapshot avant la convergence** — permet de revenir si nécessaire.
- 📌 Exporter en **PDF en fin de session** + envoyer à tous.
